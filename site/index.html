Kala · agent memory you can see

GitHub wire protocol agent ops ADRs

Kala is a clean-room reimplementation of Datomic's architecture with a memory layer for agents: every run of an agent records turns — exactly one transaction each — attributed to a session, citing the turns they derived from. Corrections never delete: the old belief stays in history, so an agent's belief state is addressable at any point in time.

This page is a static snapshot explorer — the same knowledge graph the live monitor draws, pre-rendered from real store exports. No server, no login: what you see below is read-only data, exactly as ADR-0012 intends.
